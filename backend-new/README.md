# Backend

Servicio en evolución para las APIs de la aplicación. El código, las pruebas y
los contratos se organizan por dominio dentro de este paquete.

## Desarrollo local

Instalá dependencias y ejecutá los scripts definidos por el paquete. Las
variables de entorno se obtienen por los mecanismos internos aprobados y nunca
se agregan al repositorio, a ejemplos ni a documentación.

## Controles

- Usá una base de datos local o aislada para pruebas.
- No copies datos reales ni referencias de infraestructura a fixtures.
- Las rutas, cuentas, permisos y procedimientos de despliegue se mantienen en
  documentación interna con acceso restringido.
