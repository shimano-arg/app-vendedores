# App Reclamos

Aplicación interna para registrar y gestionar reclamos operativos.

Usá los scripts declarados en su paquete para desarrollo y pruebas, con una
configuración local aprobada y datos sintéticos. La operación de servicios,
usuarios, migraciones, despliegues y credenciales se documenta fuera del
repositorio en material de acceso restringido.

No publiques datos de reclamos, clientes, cuentas, rutas locales ni secretos.
