# Scripts

Este directorio contiene herramientas de desarrollo, mantenimiento y
verificación. Cada script debe declarar su propósito, entradas, salidas y
efectos antes de ejecutarse.

Los scripts que interactúan con servicios compartidos requieren el
procedimiento interno correspondiente. No documentes ni copies aquí cuentas,
datos reales, identificadores de entornos, secretos o comandos de
administración de credenciales.
