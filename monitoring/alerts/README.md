# Alertas

Las definiciones de alertas se versionan para revisión técnica. Los destinos de
notificación, cuentas, umbrales operativos y procedimientos de respuesta se
mantienen fuera del repositorio en documentación interna de acceso restringido.

Validá la sintaxis localmente antes de proponer cambios y no incluyas
identificadores de entornos, contactos personales ni comandos administrativos.
