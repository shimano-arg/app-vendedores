# App Vendedores

Aplicación interna para la operación comercial de Shimano Argentina.

## Acceso y documentación

Este repositorio es público por necesidades temporales de hosting. La
documentación operativa, los runbooks, las incidencias, los datos de clientes,
las credenciales y la configuración de entornos se administran en canales
internos con acceso restringido. No se deben agregar aquí como sustituto de
esos canales.

## Desarrollo

Usá los scripts definidos por cada paquete y una configuración local aprobada.
No copies datos reales, tokens, claves, direcciones de infraestructura ni
exportaciones de producción a código, documentación, issues o pull requests.

## Seguridad

- Nunca versionar secretos, certificados privados, archivos de entorno ni
  credenciales de servicios.
- No incluir nombres, correos personales, rutas de equipos o datos de clientes
  en documentación.
- Mantener los cambios de infraestructura, permisos y despliegues dentro del
  proceso de revisión y autorización correspondiente.
- Reportar cualquier exposición potencial por un canal interno restringido.

Las pautas para colaboradores y asistentes están en [CLAUDE.md](CLAUDE.md).
